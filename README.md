# 点呼・業務記録（tenko-log-v1）

軽貨物の **乗務前・乗務後の点呼** と **業務記録** を、1日3回のタップで残すためのWebアプリです。
iPad / iPhone の Safari で開き、ホーム画面に追加して使います。

- 公開URL：https://negitoro375.github.io/tenko-log-v1/
- 姉妹アプリ：配達記録（[delivery-log-shachiku-v1](https://github.com/negitoro375/delivery-log-shachiku-v1)）。件数と売上はそちら、こちらは法令の記録だけを持ちます

---

## 1日の使い方

| いつ | 画面 | やること |
| --- | --- | --- |
| 局でアルコールチェックを受けたあと | 出発前チェック | アルコール「済」・日常点検「済」・体調・車両・メーター開始 → **出発する** |
| 走っている間 | 走行中 | 休憩の始めと終わりにボタン、回った地域をチップで選ぶ |
| 局に戻ったら | 帰着後チェック | メーター終了・荷待ち／荷役／異常（ふだんは「なし」のまま）→ **帰着して記録する** |

- 時刻は、ボタンを押した時刻が自動で入ります
- あとから直すと、元の値と直した日時が「修正履歴」に残ります（振り返る → 日付をタップ）
- 帰着後チェックを忘れた日は、次に開いたときにホームでお知らせします

## 最初にやること（1回だけ）

1. Safari で公開URLを開く → 共有ボタン →「ホーム画面に追加」
2. 「書き出し」タブ → 設定で、運転者名・車両・地点・よく回る地域を登録

## データの保存とバックアップ（運用保守）

記録は **この端末のブラウザの中だけ** に保存されます（サーバーには送りません）。
そのため、次のことをすると記録が消えます。

- Safari の「履歴とWebサイトデータを消去」
- ホーム画面のアイコンを削除する
- 端末の故障・機種変更

**守ること**

- 月末に「書き出し」→ バックアップ「書き出す」→ iCloud Drive に保存
- 7日以上バックアップしていないと、ホームにお知らせが出ます
- 機種変更や消えたときは「復元する」でバックアップファイルを読み込む

詳しくは [docs/operation.md](docs/operation.md)。

## 修正・機能追加の頼み方（スマホ・iPadから）

このリポジトリは、AI（Claude Code / Codex）に文章で頼んで直す前提で作っています。

1. Claude Code（または Codex）でこのリポジトリを開く
2. 例のように頼む
   - 「振り返るの一覧に、月の合計走行距離を出して」
   - 「出発前チェックに『タイヤの空気圧』を足して。CSVの列も増やして」
3. AI は [AGENTS.md](AGENTS.md) のルール（記録を消さない・CSVの列順を守る など）に従って直します
4. 直したら `main` に反映 → 数分で公開URLに反映されます

頼むときの決まりごとや、壊してはいけないところは [AGENTS.md](AGENTS.md) にまとめてあります。

## ファイル構成

```
index.html             アプリ本体（画面・見た目・処理がすべてこの1ファイル）
sw.js                  電波がなくても開けるようにする仕組み
manifest.webmanifest   ホーム画面に追加したときの名前とアイコン
assets/                アイコン
docs/requirements.md   要件定義（何を記録するか・なぜ）
docs/operation.md      運用保守（バックアップ・復元・機種変更）
AGENTS.md / CLAUDE.md  AIに修正を頼むときのルール
CHANGELOG.md           変更の記録
```
