# 要件定義

毎日の点呼と業務記録を、1日3回・合計1分程度の入力で残し、1年以上保存できる自分専用のWebアプリ。

## 目的と前提

- 使う人：自分1人。ログインなし
- 背景：2025年4月から貨物軽自動車運送事業にも業務記録の作成と1年保存が義務化。現場で点呼・記録が行われていないため、自分の身を守る記録として自前で残す
- アルコールチェック：局で毎回受けているので、アプリでは「受けた」ことだけを記録する（測定値・写真は扱わない）
- 配達記録アプリとは別アプリ。持ち出し・完了の件数は入れない（二重入力を防ぐ）。2つのCSVは日付で結合できる

## 記録項目

| 項目 | 入力方法 | 必須 | 何のための記録か |
| --- | --- | --- | --- |
| 日付 | 当日を自動 | 必須 | 業務記録 |
| 運転者名 | 設定で1回登録 | 必須 | 業務記録 |
| 車両番号 | 設定の車両からプルダウン | 必須 | 業務記録 |
| 乗務前の時刻 | 「出発する」で自動 | 必須 | 点呼 |
| 局アルコールチェック | チェック（済） | 必須 | 点呼 |
| 体調 | 良好／やや不良／不良 | 必須 | 点呼 |
| 日常点検 | チェック（済） | 必須 | 点呼 |
| 業務開始の時刻・地点 | 時刻は自動、地点はプルダウン | 必須 | 業務記録 |
| 主な経過地点 | チップで複数選択＋追加 | 任意 | 業務記録 |
| 休憩の時刻・地点 | 開始・終了ボタン、地点は入力 | 取ったら | 業務記録 |
| 業務終了の時刻・地点 | 時刻は自動、地点はプルダウン | 必須 | 業務記録 |
| メーター開始・終了 | 数字入力または音声。前回の終了値を候補に出す | 必須 | 業務記録（走行距離） |
| 乗務後の時刻 | 「帰着して記録する」で自動 | 必須 | 点呼 |
| 荷待ち30分以上 | なし／あり（内容） | 任意 | 業務記録 |
| 荷役1時間以上 | なし／あり（内容） | 任意 | 業務記録 |
| 事故・異常 | なし／あり（内容） | 必須 | 事故記録（3年保存）のきっかけ |
| 備考 | 自由入力 | 任意 | — |
| 修正履歴 | 編集時に自動 | 自動 | 後から作った記録ではないことを示す |

## 画面

1. 今日：進み具合（出発前・走行中・帰着後）と、次にやるボタン1つ。前日以前の帰着忘れとバックアップ切れを知らせる
2. 出発前チェック：乗務前点呼（青）と業務開始
3. 走行中：休憩ボタン、経過地点
4. 帰着後チェック：業務終了（緑）、走行距離の自動計算、荷待ち・荷役・異常
5. 振り返る：直近7日／30日／全期間の一覧。タップで編集（修正履歴つき）
6. 書き出し：月ごとのCSV・印刷（A4横）、バックアップ・復元、設定

画面案：デザインキャンバス（非公開、Claude内）

## CSVの列（この順番を変えない）

```
日付,運転者,車両番号,乗務前_時刻,局アルコールチェック,乗務前_体調,日常点検,業務開始_時刻,業務開始_地点,主な経過地点,休憩_時刻,休憩_地点,業務終了_時刻,業務終了_地点,メーター_開始,メーター_終了,走行距離_km,乗務後_時刻,荷待ち30分以上,荷役1時間以上,事故・異常,備考,修正履歴
```

- UTF-8（BOM付き）、日付は YYYY-MM-DD、時刻は HH:MM
- 休憩が複数回の日は「／」区切りで1セルにまとめる

## 守ること・作らないもの

- iPad / iPhone の Safari で、ホーム画面に追加して使える。電波がなくても入力・保存できる
- ボタンは親指で押せる大きさ（高さ44px以上）。1回の入力は30秒以内
- 作らない：ログイン、サーバー保存、件数・売上、アルコールの測定値と写真、GPSの自動記録、専用のPDF生成（ブラウザの印刷で代用）
