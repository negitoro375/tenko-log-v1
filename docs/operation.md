# 運用保守

記録は端末のブラウザの中にしかありません。**バックアップのファイルが唯一の控え**です。

## 定期作業

| いつ | やること | かかる時間 |
| --- | --- | --- |
| 毎月末 | 書き出し → バックアップ「書き出す」→ iCloud Drive の `点呼記録` フォルダに保存 | 1分 |
| 毎月末 | 同じ画面で、その月のCSVを書き出して保存（月次レポート用） | 1分 |
| 7日バックアップしていないとき | ホームのお知らせから「保存する」 | 1分 |

- ファイル名は `tenko-backup_YYYY-MM-DD.json`。毎回すべての日の記録が入っているので、いちばん新しい1つがあれば復元できます
- 古いバックアップも消さずに残しておくと安心です（1か月1ファイルで十分）

## 記録が消えたとき・機種変更したとき

1. 新しい端末で公開URLを開き、ホーム画面に追加
2. 書き出し → 「復元する」→ iCloud Drive のいちばん新しいバックアップを選ぶ
3. 同じ日付の記録がある場合は、ファイルの内容で上書きされます（確認が出ます）

## 消えやすくなること（やらない）

- Safari の設定で「履歴とWebサイトデータを消去」
- ホーム画面のアイコンを削除
- プライベートブラウズで使う

アプリは起動時に「データを消さないでほしい」とブラウザに頼んでいます（永続化の要求）。それでも上の操作では消えるので、バックアップが前提です。

## 法令上の保存期間

- 業務記録・点呼記録：1年
- 事故の記録：3年

アプリからは自動で消しません。1年を過ぎても、必要がなくなるまで残しておいて構いません。

## アプリを更新したとき

GitHub の `main` に反映すると、数分で公開URLに出ます。
ホーム画面のアプリは、一度開き直すと新しい版になります（設定画面のいちばん下に版番号が出ます）。
更新しても記録は消えません。
